> canonical routes：`/tasks/:taskId/results`、`questions`、`students`、`visualizations`、`reports` 及题目/学生详情

> 视觉基准：Figma 16/14、用户在 2026-07-27 对“顶部大入口、给题号侧栏留空间、搜索/侧栏/上下题保持一致”的最终覆盖要求

## 1. 本阶段结论

正式结果工作区不再使用 220px 局部左侧栏目，也不在移动端改成语义不同的下拉框。五个一级入口统一放在版本状态横幅下方，桌面等宽排成一行，窄屏只在这一行内部横向滚动：

1. 总览 / Overview
2. 题目分析 / Question analysis
3. 学生分析 / Student analysis
4. 可视化分析 / Visual analysis
5. 报告与下载 / Reports & downloads

选中态沿用 Figma 的浅蓝底、细描边和克制配色，不恢复旧版大块高饱和蓝。这样主内容获得完整宽度，题目分析与学生详情可以使用同一套 132px 题号目录，而不会出现“工作区侧栏套题号侧栏”的双层挤压。

## 2. 统一详情交互

### 2.1 共用题目目录

- A03 题目分析详情与 A05 学生分析详情共用 `ResultQuestionSidebar`。
- 桌面目录固定在全局顶栏下方 `86px`，只在目录自身超高时滚动；正文滚动不带走目录。
- 标题固定为“题目导航”，副标题按页面语义显示“共 N 题 · 点击切换/定位”，避免只显示 1/2/3 而没有用途说明。
- 当前题浅蓝高亮；绿/橙/灰状态点只表达真实完成、注意或无数据状态。

### 2.2 搜索、切换与 URL

- A02/A03/A04/A05 的文本筛选使用“草稿值 + composition 门禁”；中文输入法选词结束后才写入 URL 和执行筛选。
- 题目搜索独占一行，明确支持题号、题型、题干和可解释别名；完全匹配与相关匹配分别标注。
- 输入框聚焦时方向键只编辑文本；退出后，题目详情使用 `↑/↓`，学生详情使用 `←/→` 切学生、`↑/↓` 在连续题目中定位。
- A03 的上一题/下一题和左侧目录都只在当前筛选结果中移动；A05 的学生筛选与题目筛选互不改写。
- 切换学生时移除旧题目锚点并由共用结果壳回到页面顶部，避免正文先跳到旧题再闪动。

### 2.3 路由收敛

- 学生详情唯一 canonical route 为 `/tasks/:taskId/results/students/:studentId`。
- 旧 `/tasks/:taskId/results/:studentId` 兼容 route 已删除，不再维护第二套分流规则或旧视觉。
- 学生详情只保留连续滚动形态；`question` 查询参数仅表达进入页时的题目定位，不再切换成另一套“单题模式”，也不增加第二种页面 URL。

## 3. 完成态与返回语义

- 正式版本横幅增加真实主动作：结果未过期时进入“报告与下载”，过期时返回复核并重新确认。
- 第 8 步统一命名为“结果分析 / Results Analysis”，仍可回溯第 5“校对作答”、第 6“执行批改”和第 7“复核分析”；结果工作区顶部导航只切换正式结果内部页面，不取代任务流程条。
- 题目或学生 route 参数变化时共用壳自动回到页面顶部；同一详情中使用题号目录时才执行精确滚动定位。

## 6. 结果详情内容层级最终纠正（2026-07-27）

- A03 的“标答 / 参考答案”改为正文全宽卡片，内容随文本自然增高；只在确有超宽公式时允许横向滚动，不再把正常长答案关进固定高度纵向滚动框。
- “Rubric 维度表现”独占一整行并显示全部真实维度，长维度名换行；“易错点与常见问题（有据）”和“复核与分歧信号”在下一行各占一半。
- A05 删除“单题查看/全部题目”模式切换与聚焦详情分支。题目目录、搜索候选、卡片顶部/底部按钮和 `↑/↓` 都只负责在同一连续页面内定位；`←/→` 继续切学生。
- 学生作答详情的搜索说明与键盘说明固定为上下两行，页尾次动作统一为“返回作答总览”；正常浏览不增加额外说明卡。
- 隔离 `T_results_qa` fixture 使用 3 题、2 名学生、长标答和 5 个长 Rubric 维度完成浏览器验收；题目详情与学生连续详情均无控制台错误，未调用真实 provider。
