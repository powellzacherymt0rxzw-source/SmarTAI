# R5-06 全局中英文一致性：阶段决定与验收记录

> 日期：2026-07-24
> 范围：当前 React 前端全部 68 个用户可见源文件，以及无需任务数据即可进入的核心 route
> 状态：工程与真实浏览器验收完成，等待用户视觉确认

## 1. 本阶段目标

- 保持 Figma 已完成页面的结构、尺寸、层级和克制用色不变，只修正语言切换后的可见文案一致性。
- 教师切换到 English 后，顶栏、页面标题、空状态、错误入口和操作按钮不得继续露出硬编码中文。
- 后端返回的教师数据、文件名、任务名和题目原文属于用户内容，不进行机器翻译；供应商或后端原始错误仍按现有脱敏错误合同处理。
- 用一次静态全量审计和一次核心 route 浏览器巡检完成本阶段，不为同一页面反复截图消耗额度。

## 2. 修正内容

- 会话过期及非教师角色门禁根据当前 locale 传递中英文登录错误，不再固定返回中文。
- 404 空状态补齐中英文标题、说明和返回工作台动作；同时移除 `Link > button` 嵌套交互元素。
- 正式结果总览的局部标题改为在调用处完成 locale 选择，避免中文 literal 依赖相邻 `titleEn / descriptionEn` 才能正确显示。
- 可见范围审计新增 `raw-unlocalized-chinese` 规则，阻止中文 JSX 文本或中文 `title / description / placeholder / aria-label / message` 等 literal 属性直接进入用户界面。
- 对其余中文字符串逐项复核：双语数组、`tx(...)`、locale 分支、自然语言筛选别名和用户数据不作为硬编码缺陷误报。

## 5. 明确边界

- 当前语言偏好仍只保存在本浏览器，不同步到账号或服务端。
- 用户输入、课程名、标签、文件名、题目与学生作答按原文显示，不能把其中中文误判成界面翻译遗漏。
- 本阶段完成的是当前可见前端文案与核心入口巡检；外部供应商未来新增的错误码仍需在对应 API 接入时补双语稳定映射。
- 用户尚未逐页视觉确认，因此 tracker 保持 `[~]`，不能写成用户已验收。
