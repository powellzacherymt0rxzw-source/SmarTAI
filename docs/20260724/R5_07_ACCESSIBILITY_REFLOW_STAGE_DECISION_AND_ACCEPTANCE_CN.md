# R5-07 键盘、焦点、对比度、缩放与减弱动画：阶段决定与验收记录

> 日期：2026-07-24
> 范围：全局壳、认证边界、核心无数据 route、课程资料库对话框及任务未保存确认
> 状态：工程与自动浏览器验收完成，等待用户视觉/读屏抽查

## 1. 设计与实现原则

- 不改变 Figma 的页面层级、信息密度和静态视觉骨架；可访问性修正只作用于焦点态、危险操作对话框、响应式断点、语义色深度和用户明确要求减弱动画的场景。
- 不为装饰性图标增加重复读屏文本；图标继续 `aria-hidden`，真实动作由按钮或链接名称表达。
- 未保存确认必须默认聚焦安全动作、Tab 不逃出、Escape 留在原页、关闭后恢复原焦点，并锁定背景滚动。
- 颜色继续克制使用；只把语义 teal/orange 调深到普通正文 AA 对比度，不增加新颜色。

## 2. 完成的修正

### 2.1 键盘与焦点

- 新增共享 `UnsavedChangesDialog`，替换题目逐项校对、批改设置、资料导入、资料匹配复核和 AI 补全范围页的重复离开确认。
- 共享确认框提供 `alertdialog`、`aria-modal`、标题/说明关联、默认安全动作、Tab/Shift+Tab 焦点循环、Escape 取消、关闭后恢复原焦点及背景滚动锁。
- 新建任务原有离开确认补背景滚动锁和清晰 `focus-visible`；保留其已实现的焦点循环、Escape 和恢复语义。
- 课程资料库对话框改用稳定 `useId`，补 `aria-describedby` 和关闭后焦点恢复。
- `Button` 默认 `type="button"`；表单提交仍显式使用 `type="submit"`，避免组件被放入表单后意外提交。
- 学生端边界页移除 `Link > Button` 嵌套交互；新建任务智能候选使用 `aria-activedescendant` 时，候选按钮退出重复 Tab 顺序并保留焦点指示。

### 2.2 对比度与动画

- 浅色语义 `accent` 从 `#0d9488` 调整为 `#0f766e`，`warning` 从 `#d97706` 调整为 `#b45309`。
- 浅色正文/语义色在白色或 `#f8fafc` 背景的最低对比度为 muted `4.55:1`；primary `4.94:1`、accent `5.23:1`、warning `4.80:1`、danger `4.62:1`。
- 深色主题对应语义色在 card 上最低为 primary `4.90:1`，其余均高于 `5.29:1`。
- 全局新增 `prefers-reduced-motion: reduce`：动画和 transition 缩短为 `0.01ms`、仅运行一次，并关闭平滑滚动；生产 CSS 已确认包含该 media rule。

### 2.3 缩放与回流

- 浏览器自动巡检在当前 `1280px` CSS 视口发现工作台 CTA 向右溢出 `42px`。原因是 Figma 的 `1290px` 固定指标骨架过早在 Tailwind `xl=1280px` 启用。
- 固定六列骨架现在只在 `min-width: 1400px` 启用；`1280px` 复验为 `scrollWidth=clientWidth=1280`，而 `1440px` Figma 布局保持原结构。
- 其他核心 route 在 `1280px` 均无页面级横向溢出；此前各阶段的 `390×844` 证据是比常见 1280px 页面 200% 缩放后约 `640px` CSS 视口更严格的回流检查。
- 浏览器连接本轮不提供可临时覆盖 viewport 的能力，因此最终用户验收仍保留一次浏览器原生 200% 视觉抽查；工程判断不伪装成该人工检查已完成。

## 3. 防回归

visible-scope audit 在原有产品边界和 i18n 检查之外新增：

- 禁止 `Link/a` 与 `Button/button` 互相嵌套。
- 原生 `<button>` 必须显式声明 `type`。
- 交互元素使用 `outline-none` 时必须同时提供显式 focus/focus-visible 指示。
