## 1. 阶段结论

A03 已替换遗留单题结果页，并继续使用 A00 的正式结果五入口工作区。页面只负责“一道题的完整分析 + 少量学生分流”，不在这里纵向铺开全班完整答案。

- 顶部显示题号、题型、当前序号、上一题/下一题与上下键提示。
- 独占一行的智能查找支持题号、题干、题型、真实知识点及少量透明别名，并明确区分“完全匹配 / 相关匹配”；旁边保留直接选择题目。
- 六张圆角指标卡显示作答人数、平均分、中位数、最低/最高分、平均置信度、必审/分歧次数。
- 题干、评分标准、标答/参考答案、代码/测试资料各自成卡并显示真实来源或“未提供”；数学内容继续使用 KaTeX 渲染。
- 分析区只汇总可从正式结果证明的重复评分反馈、rubric 步骤和复核/分歧信号，不由前端杜撰“AI 易错点”。
- 学生区仅按得分率从低到高预览 5 位，并进入 canonical 学生详情；完整作答留给 A05。

## 2. 导航与上下文

- `↑ / ↓` 分别切换上一题/下一题；输入框、选择框或可编辑区域聚焦时不会劫持方向键。
- 顶部和页底均有题目切换按钮，长内容不要求教师滚回页面开头。
- A02 进入详情时会把题目总览的筛选、排序和页码编码进 `return`；返回题目总览以及在详情之间切题后仍可恢复原条件。
- 浏览器实测 `积分题` 显示 Q2 为“相关匹配”，`Q3` 只显示一个“完全匹配”；Q2 上按下方向键进入 Q3、再按上方向键返回 Q2。
- 学生摘要链接保留当前题目参数和锚点：`/results/students/:sid?question=:qid#question-:qid`。A03 只补了该 canonical route 的兼容入口，A05 才会替换其遗留视觉，不能把学生详情写成已经完成。

## 3. 数据与模型调用边界

- 所有统计均由已加载的不可变正式结果快照计算，教师最终覆盖分优先；不新增伪造 fixture 字段。
- 置信度兼容后端 `0–1` 与 `0–100` 数值；中位数、最低/最高分只基于真实作答。
- 资料来源只读取正式题目已有 provenance / AI completion provenance；无来源时明确显示“题目识别 / 教师维护”或“未提供”。
- 常见问题按重复评分反馈计数；rubric 维度按真实步骤描述、得分和正确标志聚合；复核信号来自低置信、正式复核原因和专家分歧事实。
- 本页不调用 per-question breakdown provider。遗留 breakdown GET 在缓存缺失时可能触发模型调用，因此 A03 选择确定性读取已有结果，避免用户只是打开页面就消耗 BYOK/共享额度。

## 4. 页面长度与响应式

- 1440px 桌面首屏先显示工作区、题目导航、搜索、六指标和全部四类题目资料；证据与学生摘要继续向下，避免把全班答案塞入首屏。
- 390px 移动端按单列展开；材料本身较长时只在资料卡内部滚动，页面无横向溢出。
- 本阶段没有把“批量筛选全班学生”塞入题目详情；该能力属于 A04/A05，符合一个 route 一个焦点的拆分原则。
