### 3.2 后端确定性合同

全量回归覆盖：

- 重复启动返回 `already_running` / `already_done`，不会重复消费模型；
- 任务、材料、草稿、专家和结果按 owner 隔离；
- 任务/草稿配额返回稳定 `429`，不驱逐其他用户数据；
- PDF 提取超时返回稳定 `408`，字符/token/文件限制返回稳定 `413`；
- Q08 无可用 BYOK 返回稳定 `503`，失败 plan 可以安全重试；
- 批改 quota/timeout/失败专家不会污染成功专家权重，并给出可恢复建议；
- 过期 workflow revision、复核覆盖、finalization 和 artifact 生成使用 CAS/幂等保护；
- API key、学生内容、供应商原始异常和实现细节不进入用户可见错误或 INFO 日志。
