## 1. 阶段结论

A04 已把六行占位学生列表替换为正式结果的完整学生统计总览。页面只做“全班比较、筛选、排序与进入学生详情”，不在总览展开完整答案。

- 六张大号圆角指标卡：学生数、平均得分率、中位得分率、最低/最高得分率、及格率、含必审信号的学生数。
- 自然语言搜索独占一行，解释出的条件显示为可移除标签；结构化得分、及格、置信度、复核和排序另起一行。
- 桌面为学生 × 题目矩阵：姓名/学号、总分、得分率、及格状态、平均置信度/复核摘要，以及每题“得分 / 满分 + 得分率”。
- 题目单元格可进入该学生详情并聚焦当前题；行尾进入该学生全部题目视图。
- 每页只显示 5 位学生，避免大班级默认一次铺满；筛选、排序和页码写入 URL。

## 2. 自然语言与结构化筛选

本阶段继续使用确定性、可解释的本地解析，不调用 provider：

- 姓名、学号普通关键词；
- `得分率低于 N% / 至少 N%`、`及格 / 不及格`；
- `低置信`、`待复核 / 已复核 / 无复核`；
- `低分优先 / 高分优先`。

浏览器实测 `Alice 低置信 已复核 低分优先` 解析为 4 个可移除条件，并只命中真实 Alice（1/6）。条件、结构化选择器和分页可组合。

正式结果契约当前只有 `student_id / student_name / corrections / student_answers`，没有学生标签字段。因此 A04 不把任务标签、课程或姓名片段冒充学生标签；标签筛选保留为后端增加 owner-scoped 学生标签契约后的扩展项。

## 3. 数据与复核口径

- 总分和逐题得分优先使用教师最终覆盖分；所有均值、中位数、范围和及格率只基于真实正式结果。
- 无可比总分时显示 `--` 并可用“无可比总分”筛选，不默认判定为不及格。
- 置信度兼容后端 `0–1` 与 `0–100`；低置信阈值保持 0.65。
- 必审状态同时考虑低置信、后端显式人工复核、正式复核原因、模型全部失败/额度失败与可证明的专家分差；只有所有必审题次 `review_status=confirmed` 才显示已确认。
- 每题与行详情使用 canonical `/results/students/:sid`；携带 `question`、锚点和 A04 `return` 条件。该详情视觉由紧接的 A05 替换。
