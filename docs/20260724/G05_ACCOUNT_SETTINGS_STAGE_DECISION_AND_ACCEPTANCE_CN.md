> 状态：实现、工程检查及桌面/移动浏览器验收完成，等待用户视觉确认

## 1. 阶段决定

Figma 17 张导出图没有独立账户设置页，因此本阶段不凭旧页面惯性扩展新功能，而是落实已经确认的导航决定：

- 账户设置、模型与 BYOK、退出登录只放在最右侧用户名菜单，不进入顶部主导航。
- G05 只负责账号资料和本地界面偏好；模型密钥留给 G06 独立页面。
- 账号 API 只返回只读会话资料，因此不显示不可用的修改用户名、邮箱、密码或安全状态按钮。
- 删除旧页面的后端 URL、CPU、内存和健康检查；这些属于开发/运维信息，不是教师账户设置。

## 2. 视觉约束

- 沿用 70px 顶栏和 1300px 主列，标题与 Figma 全局页保持同一左边界和字号层级。
- 账号摘要使用一个单层白色面板，头像、用户名和克制的“已登录”状态位于同一头部；用户名、邮箱、角色在同一事实行。
- 界面语言与外观各占一个宽行，右侧使用低饱和 segmented control；不堆叠 Card、说明框或彩色胶囊。
- 底部只有一条必要边界说明，解释模型设置与退出入口仍位于用户名菜单。

## 3. 真实功能

- 账号名、邮箱和角色来自 `/auth/me` 的当前登录用户，不使用 fixture 或浏览器自造资料。
- 中文/English 切换会同步更新全局导航、账户页和菜单文案。
- 浅色、深色、跟随系统会立即更新主题，并继续使用项目已有浏览器本地偏好存储。
- 用户名菜单实测存在账户设置、模型与 BYOK、退出登录三个入口；退出登录沿用真实 `/auth/logout` 和本地 token 清理流程。
- G05 没有修改认证或用户后端，也没有调用 provider。
