## 1. 页面职责

A06 只负责正式结果版本的统计图表，不复刻题目、学生详情，也不把报告下载混进本页。默认图表全部由浏览器对不可变正式结果做确定性计算，不调用 provider；只有教师主动提交自然语言请求时才发起一次既有安全图表接口调用。

顶部使用六个独立圆角指标卡显示当前样本、平均数、中位数、最低/最高、及格率和含必审信号人数。页面可按全部、及格、未及格或含必审信号切换统计范围，范围写入 URL，所有指标与默认图表同步更新。

## 2. 默认图表及教学用途

页面使用真实 `recharts@3.10.0`，没有用 CSS 柱条冒充图表：

1. 得分率分布柱状图：观察集中区间和成绩尾部。
2. 及格构成环形图：只比较互斥的及格、未及格与无可比总分，避免把复核状态混入饼图。
3. 逐题平均得分率与必审题次数组合图：同时定位薄弱题和证据风险。
4. 得分率 × 平均置信度散点图：每个点对应一名学生，红色只表示正式结果中存在必审信号。
5. 学生 × 题目 SVG 热力图：单元格保留真实百分比，最多显示当前范围前 100 名并明确标注。

每张图均显示样本数、正式结果版本、筛选范围、用途说明和题目/学生明细入口。默认图表无需生成任务，也不伪造“分析已生成”。

## 3. 自然语言图表安全边界

- 不在页面进入、筛选或默认图表渲染时自动调用模型。
- 教师点击“确认生成”后才调用现有 `/analytics` chart 模式一次。
- 后端 `ChartOutput` 只允许 `bar / scatter / pie / histogram / box`，最多 4 条 trace、每条最多 50 个点；前端再执行相同白名单与数量截断。
- `bar / histogram / pie / scatter` 使用真实 Recharts；`box` 使用真实四分位数、须、箱体和中位线 SVG，不以柱状缩略图冒充。
- 本阶段浏览器验收没有调用真实 provider；后端 schema 定向测试覆盖接口合同和类型门禁。

## 4. 导出与保存的真实能力

- 每张默认图表可把实际 SVG 光栅化为 PNG；多 trace 自定义结果按钮明确写为“首图 PNG”，不暗示已经导出全部 trace。
- “打印 / 存为 PDF”调用浏览器打印能力，教师可在系统打印面板保存 PDF；当前不是后端生成的版本化 PDF artifact。
- 自定义图表可保存、删除和恢复默认图表，但保存仅限当前页面访问内存，刷新后清空；页面已直说后端持久化和版本历史仍待接入。
- 正式的成绩表、学情报告、发布版标答、Markdown/LaTeX 与版本化批量下载属于 A07。
