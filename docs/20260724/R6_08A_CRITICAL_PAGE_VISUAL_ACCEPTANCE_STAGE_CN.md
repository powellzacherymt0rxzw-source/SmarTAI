## 2. 本阶段发现并修复的问题

直接交互验收时，学生先精确切换为 Bob 后，在题目维度输入“积分题”，含 TeX `\\int_0` 的 Q1 没有被返回。原因是透明语义别名只识别中文“积分”、英文 integral 和 Unicode `∫`，没有识别题干中的 TeX `\\int` 命令。

修复位于 `frontend/app/src/lib/reviewDetail.ts`：积分别名现在同时识别中文/英文、TeX `\\int` 与 Unicode `∫`。这仍是零 provider、可解释的有限别名，不冒充通用语义搜索。

修复后交互结果：

1. 学生输入 `Bob`，显示 `20260002 · 完全匹配`，选择后仍停在 Q2；
2. 题目输入 `积分题`，显示 `Q1 · 计算题 · 相关匹配`；
3. 选择 Q1 后 URL 为 `/review/20260002/q1?student=Bob&question=积分题`，学生维度保持 Bob，不被题目筛选改变。
