## 1. 阶段结论

A02 已把题目分析占位列表替换为真实、可筛选、可排序且适合长期复看的题目统计总览。页面不在总览下方铺开每名学生的完整答案；每行只显示题目粗略统计和进入单题详情的入口。

- 顶部四项大指标：题目数、题目平均得分率、低于 60% 的题目数、含正式必审信号的题目数。
- 独占一行的自然语言筛选框；解析后的条件以可移除标签显示。
- 结构化筛选：题型、得分率、置信度、复核状态；排序支持题号、得分率、置信度和复核信号。
- 每题显示题号/题型/题干、后端真实知识点、作答人数、平均分/得分率、平均置信度、低置信题次数、正式必审确认状态和事实风险摘要。
- 每页 4 题；桌面为单一矩阵表，移动端为纵向卡片，均无页面级横向滚动。

## 2. 智能筛选边界

本阶段采用确定性、可解释的本地解析，不调用 provider，因此不会为了每次输入消耗模型额度，也不会把关键词匹配冒充深层语义理解。

支持的可解释条件包括：

- `Q3 / 第 3 题` 等题号；
- 已有题型名；
- `得分率低于 70% / 至少 80% / 薄弱题`；
- `低置信 / 平均置信度低于 65%`；
- `待复核 / 已复核 / 无必审项`；
- `知识点未标注`；
- 题干、题型、知识点普通关键词，并对 `积分 / 微分 / 证明 / 编程` 提供少量透明别名。

实渲染验证：输入 `积分题 低置信 已复核` 后页面显示三个可移除条件，只命中真实题干含积分符号/文字、含低置信题次且必审项已确认的 Q2；移除“积分题”标签后 URL 和结果同步更新。

真正的 provider 语义检索、拼音模糊匹配、后端大数据分页和跨任务知识点语义仍未在 A02 声称完成。

## 3. 数据与复核口径

- 平均分和得分率优先使用教师最终覆盖分；模型由既有 `buildResultsModel` 统一计算。
- 平均置信度对后端 `0–1` 和 `0–100` 两种数值形式做归一化。
- 正式必审信号复用 A00 的事实规则：低于 0.65、后端显式标记、专家分歧/分差、全部失败或额度失败。
- “易错 / 风险摘要”只汇总可证明的低平均得分率、低置信题次和专家分歧次数；没有真实信号时明确写“暂无由现有结果支持的明显风险信号”，不生成虚假错误主题。
- 知识点只读取后端真实字段；当前任务未标注时显示“知识点未标注”，前端不猜测。

## 4. 页面职责与下一跳

- 桌面表格只保留题目摘要和统计，不显示学生答案正文。
- 移动端以相同数据压缩为卡片，不把宽表强行塞进 390px 页面。
- `详情` 使用 canonical `/results/questions/:qid`；A02 提交时该 URL 仍由遗留详情实现兜底，紧接的 A03 会在同一正式结果壳内完全替换其视觉与双向分流。
- 筛选、排序和页码进入 URL，刷新/返回不会丢失条件。
